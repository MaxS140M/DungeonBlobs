# The Lantern Vault

A small top-down dungeon crawler made with Pygame.

## Run

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Controls

- `WASD` to move
- `Space` or left mouse button to attack
- Collect all three relics, then reach the green exit
- `R` restarts after winning or losing
- `Esc` quits
